# AETHER Implementation Plan

> **For agentic workers:** Execute with superpowers:executing-plans (inline). Steps use checkbox (`- [ ]`) tracking.

**Goal:** Cinematic scroll-driven 3D cosmic experience website at ThreeUI quality bar.

**Architecture:** Single fixed R3F Canvas; body scrolls 800vh; normalized damped progress drives a Catmull-Rom camera path and per-section scene mounting. DOM overlay (preloader, dock, rail, copy) synced via zustand.

**Tech Stack:** Vite + React 19 + TS, three, @react-three/fiber v9, drei, @react-three/postprocessing, @react-three/rapier, zustand. All visuals custom GLSL, zero external 3D assets.

**Spec:** `docs/superpowers/specs/2026-09-03-aether-3d-experience-design.md`

**Deviations from spec (agreed autonomy):** custom damped-scroll rig instead of gsap ScrollTrigger; CSS glass/glow buttons instead of GLSL shader buttons (same visual result, fewer fragile moving parts); particle counts tiered 100k/40k/15k.

**Verification model:** visual/interactive GLSL domain — no unit tests possible without headless GL. Every task verifies with `npx tsc --noEmit` + `npx vite build`; final task adds runtime smoke check via dev server. Commits at each milestone.
